TEVIN'S README GENERATOR


Description
TEVIN'S README GENERATOR is a command-line application that generates a professional README.md file based on user input. This tool simplifies README creation for GitHub projects, ensuring consistency and saving time for developers.

Usage
Run node index.js from the project directory. You will be prompted to answer a series of questions about your project.
Based on your responses, the application will generate a README.md file in the project directory.
The generated README will include sections such as Title, Description, Installation, Usage, License, Contributing, Tests, and Questions, with a functioning Table of Contents for easy navigation.
